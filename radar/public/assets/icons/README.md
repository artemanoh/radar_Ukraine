# Векторні тактичні іконки цілей (Tactical 2D SVG Target Assets)

Усі SVG-іконки у цій директорії створені спеціально для проєкту «РАДАР — Національний моніторинг повітряного простору».
Вони мають чіткі геометричні контури, високу контрастність на темних картографічних підкладках і не порушують жодних авторських прав (ліцензія MIT / Public Domain).

### Перелік іконок:
1. `drone.svg` — Ударний БпЛА (Shahed / дельтоподібне крило з вертикальними кінцевими стабілізаторами та вектором напрямку).
2. `missile.svg` — Крилата ракета (аеродинамічний корпус, прямі розгорнуті крила, хвостове оперення).
3. `ballistic.svg` — Балістична ракета (конічний гіперзвуковий профіль з дельтоподібними стабілізаторами та полум'ям прискорювача).
4. `recon.svg` — Розвідувальний БпЛА (довгі крила планера високого подовження, дводіагональна хвостова балка, оптичний сенсорний блок у носовій частині).
5. `area_target.svg` — Орієнтовна зона загрози (`areaOnly: true`) (пунктирне радіальне кільце з тактичним прицільним перехрестям, без жодних емодзі).
